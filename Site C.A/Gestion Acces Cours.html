COMPETENCE ACADEMY

Administration de l’espace de formation

Gestion des accès et des codes des formations

Cette page d’administration sert à rechercher un compte étudiant, vérifier ses accès, créer ou renouveler le code d’une formation et retirer un accès.

Les nouveaux codes d’accès sont enregistrés de manière chiffrée pour pouvoir être consultés ici sans les renouveler. Les codes créés avant cette fonction ne peuvent pas être récupérés et devront être renouvelés une seule fois si l’étudiant les a oubliés.

Connexion administrateur

La clé reste dans cette page pendant votre session de navigation et n’est jamais envoyée aux étudiants.

Backend utilisé :

Rechercher un étudiant et consulter ses accès

Créer ou renouveler le code d’une formation

Le code est envoyé à l’adresse de l’étudiant et aux adresses d’administration configurées, puis affiché ici après sa création. Si un code existait déjà, il est remplacé et l’ancien ne fonctionne plus.
