Administration de l’espace de formation

Gestion des accès et des codes des formations

Cette page d’administration sert à rechercher un compte étudiant, vérifier ses accès, créer ou renouveler le code d’une formation et retirer un accès.

Vous pouvez aussi téléverser les vidéos MP4 depuis cette page. Le fichier est envoyé au backend Render et conservé dans le dossier vidéo configuré. Pour que les vidéos restent après un redéploiement, le backend doit utiliser un disque persistant.

La clé d’administration est privée : configurez COURSE_ADMIN_API_KEY dans les variables d’environnement du backend Render et ne la communiquez jamais aux étudiants.

Connexion administrateur

La clé reste dans cette page pendant votre session de navigation et n’est jamais envoyée aux étudiants.

Téléverser une vidéo de cours

Choisissez une formation puis ajoutez chaque MP4 séparément. Chaque nouvel envoi s’ajoute à la fin de la liste du cours ; les vidéos déjà envoyées ne sont pas remplacées. L’application n’impose pas de limite de taille par fichier, mais le transfert dépend de la connexion, de l’espace disponible sur le disque Render et des règles de l’hébergeur.

État des vidéos sur le backend

Configuration indispensable sur Render : attachez un disque persistant au backend, avec par exemple le point de montage /var/data, puis définissez COURSE_VIDEO_DIR=/var/data/private-videos. Ajoutez aussi l’adresse Netlify exacte de votre site dans FRONTEND_URLS du backend (sans supprimer les autres adresses déjà configurées), puis redéployez le backend.

Le formulaire n’impose pas de taille maximale. L’espace de stockage du disque reste limité par la capacité choisie sur Render ; la plateforme, la connexion ou le navigateur peuvent également limiter ou interrompre les transferts très volumineux.
